NVIS Products

Providing Unique Lighting & Illumination Solutions for Aircraft, Tanks, and Armor Vehicles

Full NVG Adaptation with LED Technology

We provide full adaptation to NVG with LED's latest technology. Low cost with minimum changes, easy to install with no wiring changes. Mostly use of the original light housing already exist.

SAE-P-7788 Compliant
MIL STD-3009 (MIL-L-85762A)

Interior Lights Adaptation

NVG-compatible interior lighting for aircraft and armor vehicles without interruption to goggles operating in IR range

Instrument Bezels

NVIS solutions for all instruments. The bezel provides flood NVIS green light over each instrument, installed with original mounting screws. Connected with a small plug to interior light - no interference to pilot's naked eyes.

NVIS Edgelite Panels

High-performance edgelight panels for instrument panels and displays. Maintains NVG Gen III compatibility with uniform light distribution and no IR radiation interference.

Cargo Dome Lights (C130)

3-mode LED module replacing 2 lamps (red, dual). Includes 2 plugs with lamp base. Uses original housing with same A/C wiring. Available as complete assembly.

Cargo Floor Lights (C130)

D/M LED/IR Module with plug and lamp base. Direct replacement of original lamp using original housing. No wiring changes required. Available as complete assembly.

NVIS Flood Lights

Supply NVG filter or complete new assembly. Filters for flood lights, LED modules replacing existing lamps, special legend modules, post light caps.

NVG Legend Modules

Warning panel legend modules with NVIS compatibility. Keeps original colors with no interference to naked eyes. Used in most adapted aircraft.

Post Light Caps & NVG Lamps

Replace original caps with NVIS green caps. T-1/3 NVG Lamps replace standard T-3/4 lamps (clear or red) with NVIS green versions.

Display & Monitor Adaptation

Adaptation of indicators, displays, and monitors with NVIS compatibility. Principle: keep original colors with no interference to naked eyes.

NVIS Exterior Lights

Dual Mode LED modules (Normal/IR) for all exterior lighting applications

Landing & Taxiway Lights

LED module with dual mode white LEDs and IR LEDs. Optional laser diode for long range beam (3 modes). Same size as GE Lamps PAR-36, 46, 64. Uses original housing with new NORMAL-OFF-IR switch.

Position Lights Dual Mode

New D/M cap with GREEN/IR and RED/IR LEDs. Replaces original cap and lamp using original mounting screw and housing. No wiring change. Includes plug with original lamp base.

Tail Light D/M Module

LED D/M module with plug and lamp base. Installation by replacing original lamp with new module. Uses original housing and clear cap.

Formation Lights (C130)

Replace original lamp with LED D/M module. No wiring change required. Available with complete new assembly.

Anti-Collision Beacons (CH-53, C130)

Dual Mode LED – Normal (RED or WHITE) and IR LEDs. 3 operating modes: FLASH, ROTATING, STROBE. Replaces original lamp unit using same housing. Can supply as complete unit with new housing.

UH-60 3 Modes System

Exterior XCENON lamps replaced by 2 LED modules. 3 modes: Red LED strobe (upper), D/M LED strobe NORMAL (white + IR) bottom. New toggle switch replaces original 2-position switch.

F-16 Exterior Lights

LED D/M modules replace original lamp assemblies. Landing lights replace original HEXAGON lamps with 2 dual mode LED modules (NORMAL/IR modes).

Search Lights

Replace original GE lamp with new LED dual mode module. Uses original housing for seamless integration.

Control Systems

Dual Mode Control Kit

Cockpit panel kit with 3 positions: NORMAL - OFF - IR. Replaces original ON-OFF switch. Electronic unit sends 2 different signals on same original wires. Rotary switch option for 3-mode control.
